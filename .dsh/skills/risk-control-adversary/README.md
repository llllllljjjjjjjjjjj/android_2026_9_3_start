# risk-control-adversary — Skill 结构与产出说明

> 风控对抗方案设计师（攻防双向）：核心产出是**请求策略与真人模拟方案**（逆向期最小化触发风控、数据期像真人一样拿数据），并支持**风控体系评估**（防御侧加固）。触发词与工作流见 SKILL.md。

## 一、目录结构（三级分层知识库）

```
risk-control-adversary/
├── SKILL.md                        ← 主体：触发词 + 工作流 A（生成方案，含 A2.5 动态优先级/A3.5 验证闭环）
│                                     + 工作流 B（学习文档）+ 工作流 C（风控体系评估）+ 异常容错 + 协作边界
├── README.md                       ← 本文件
├── TESTING.md                      ← 测试记录档案
└── references/                     ← 按需加载（增量：先读索引，再按平台+维度加载）
    ├── templates.md                ← L0 格式契约：三类模板 + 证据/置信度数值阈值 + 四级标签体系 + 生命周期 + §7 策略转脚本交付模板
    ├── general-principles.md       ← L1 基础原理层：§0 使用规则（重合判定/沉淀准入/检索/生命周期/F→E 转化/跨平台适配）+ E-/F- 条目索引与正文
    ├── scenarios/                  ← L2 场景方案层：典型场景成套方案
    │   └── _index.md
    └── projects/                   ← L3 项目定制层：单项目风控记录
        ├── _index.md
        └── <target>.md
```

| 文件 | 作用 | 加载时机 |
|---|---|---|
| SKILL.md | 六维模型、动态优先级、验证闭环、分级方案、异常容错、协作映射 | 触发时全量加载 |
| templates.md | L0 格式契约：§1 方案（分级版本+对照组）、§2 项目记录、§3 E-/F- 条目、§5 零基线兜底、§6 标签体系 | 生成/沉淀时读 |
| general-principles.md | L1 通用规律（E-/F- 条目，含证据等级+置信度+标签） | 分析前按平台+维度增量加载 |
| scenarios/_index.md | L2 场景方案索引 | 匹配场景时读 |
| projects/_index.md | L3 项目索引（含平台列） | 分析前读 |

| # | 产出 | 写入位置 | 触发时机 |
|---|---|---|---|

## 三、核心升级点（相对旧版）

- **五维 → 六维**：新增「业务规则风控」维度（账号属性/交易行为/用户画像/业务异常规则）
- **固定行为优先 → 场景化动态优先级**：弱签名平台行为优先，强签名/强硬件指纹平台算法优先
- **证据等级 3 档 → 5 档 + 数值阈值**：已实证/大样本/小样本/推测/未知，按「复现次数 R × 样本量 N」量化判定；置信度按信源分级，与证据等级正交独立（templates.md §3.1）
- **只增不覆盖 → 融合去重**：核心原理重合判定粒度（检测原理+对抗思路二元组）、评审流程与合并/补充行格式（general-principles.md §0.3）
- **新增 F- 失败经验**：结构化沉淀踩坑，避免重复踩雷；含影响分级/适用风控版本/失效条件 + F→E 转化机制（general-principles.md §0.9）
- **新增生命周期管理**：失效标记（生效/待验证/已作废）、版本号与补充/修正留痕、冲突条目仲裁规则（general-principles.md §0.8）
- **标签三级 → 四级体系**：领域-平台-难度-主题，固定顺序 + 受控词表 + 新增/同义合并规则 + 标准检索路径（templates.md §6）
- **新增策略转脚本交付**：脚本参数配置表模板与交付标准（templates.md §7），明确「本 skill」= 方法论 + 知识库（非脚本库）
- **新增验证闭环**：非偶然性多维验证 + 四级梯度 + 资源隔离 + 对照组 A/B
- **新增分级方案输出**：风险（保守/平衡/激进）× 成本（低/中/高）
- **新增零基线兜底模板**：资料极薄场景直接起步
- **新增差异化变异**：注入随机变异因子，避免统一指纹
- **新增工作流 C（防御侧）**：风控体系评估与加固建议
- **跨平台**：Android/iOS/Web/小程序 标签维度；跨平台条目含「平台适配」字段（general-principles.md §0.10）
